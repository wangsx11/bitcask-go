# M0 测试与性能基线

## 环境

- 日期：2026-07-25
- 系统：macOS / darwin arm64
- CPU：Apple M5
- 实际 Go：go1.26.5
- 模块声明：Go 1.23.0，toolchain go1.23.8
- 索引与同步：默认 ART，`SyncWrites=false`
- Value 大小：1024 bytes

实际 Go 版本高于模块声明版本。本基线只用于当前机器上的后续纵向比较；跨机器或跨 Go 版本的结果不能直接比较。

## 可直接复用的测试指令

以下命令均在 `bitcask-go` 项目根目录执行。

### 日常修改后的快速测试

```bash
make test
```

等价的 Go 命令：

```bash
go test -count=1 ./...
```

### 提交代码前的完整门禁

```bash
make verify
```

该命令依次执行普通测试、`go vet` 和 race 测试，等价于：

```bash
go test -count=1 ./...
go vet ./...
go test -race -count=1 ./...
```

### 检查测试稳定性

```bash
make test-repeat
```

它会连续执行十轮测试：

```bash
go test -count=10 ./...
```

### 只运行性能基准

```bash
make bench
```

等价的 Go 命令：

```bash
go test ./benchmark -run='^$' -bench=. -benchmem -benchtime=200ms -count=5
```

### 重新生成一份完整基线

```bash
make baseline
```

该命令会执行十轮稳定性测试、vet、race 和五轮 benchmark。它耗时最长，适合阶段开始、阶段结束或准备比较性能优化前执行。

需要保存原始输出时可执行：

```bash
make baseline 2>&1 | tee m0-baseline.txt
```

单独比较性能修改前后时可分别执行：

```bash
make bench 2>&1 | tee benchmark-before.txt
# 完成性能修改后
make bench 2>&1 | tee benchmark-after.txt
```

## 正确性门禁

以下检查均已通过：

```bash
go test -count=10 ./...
go test -race -count=1 ./...
go vet ./...
```

多 GiB 的 MMap 启动实验已从默认单元测试中移除并标记为手工实验，避免日常测试生成大量磁盘数据。

## Benchmark

执行命令：

```bash
go test ./benchmark -run='^$' -bench=. -benchmem -benchtime=200ms -count=5
```

五轮结果范围：

| 操作 | ns/op | B/op | allocs/op |
| --- | ---: | ---: | ---: |
| Put | 1947–2285 | 1350 | 8 |
| Get | 1371–1402 | 1456 | 5 |
| Delete | 1226–1336 | 120 | 5 |

基准实现保证每个 benchmark 使用独立临时数据库；Get 使用固定随机种子并只读取已存在 key；Delete 在计时前预先写入待删除 key。当前数字是 M0 基线，不代表生产负载表现。

## 后续比较规则

后续性能修改应保持机器、Go 版本、配置和 benchmark 参数一致，并同时比较延迟、分配和正确性门禁。建议保存原始输出，再使用 `benchstat` 比较多轮结果；没有统计显著性的变化不视为优化收益。
